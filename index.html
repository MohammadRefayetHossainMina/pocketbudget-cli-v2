PocketBudget CLI

A terminal personal-finance app with separate domain, storage, and CLI layers. This page loads the same Python files in your browser — balance rules, custom errors, and JSON save/load are not reimplemented in JavaScript.

  • Python
  • pytest (26 tests)
  • JSON
  • GitHub Pages

What this shows

  • Balance is private — you cannot assign account.balance directly
  • Overdrafts, zero amounts, and unknown categories raise typed errors and leave state unchanged
  • Expenses over $100 need confirmation, matching the CLI --confirm flag
  • Storage rebuilds an account through public methods, so a corrupt file cannot quietly load a wrong balance

Demo uses the made-up sample in data/budget.json. Do not enter real bank details.
