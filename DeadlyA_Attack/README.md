# Deadly Attack — The Neon Shadow

**This folder is one file on purpose.** Open `index.html` — CSS and the game are inside it. You do not need a server, `js/`, or `css/`.

1. Save `index.html` (the whole file, not a GitHub preview page).
2. Double-click it. The page must be **dark**, with a black game window under the title.
3. Press **Enter** to start.

If you only see a white page and a black “Deadly Attack” heading, you opened an old/incomplete download. Use this file instead.
